Approval

A maintainer listed in data/maintainers.toml must approve the issue.

Approval is the approved label on the issue. The bot accepts that label only from a listed maintainer.

After approval, the bot opens a pull request with the data change. Merging that pull request applies it.

An ml-rust organization member never approves a judgment on an org-affiliated entry.

Every judgment is public: the issue, your login, the evidence and the approver appear on the entry page.

Read the rules before you file a judgment.
