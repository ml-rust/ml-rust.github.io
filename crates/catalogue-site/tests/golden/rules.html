Tier rules

Tiers come from fixed thresholds over raw signals. There is no composite score.

Stars never count toward a tier. GitHub hides stargazer lists, so stars cannot be screened for fakes.

No language model decides a tier. A human judgment changes an entry only through an approved issue and a merged pull request.

Thresholds version 3.

Calibrated on 2026-11-03.

The values stay frozen until the yearly recalibration. Any change raises the version.

Tiers

Featured
Shown first. It passes every Featured gate.
Listed
Shown in the normal listing. No other tier applies.
New
A young, prerelease or barely used project.
Archived
No longer maintained, or ended by its author.

The check applies the rules below in order. A signal that is missing counts neither way.

Instant archive

Any one of these signals archives an entry at once.

  • The repository is archived.
  • RustSec lists an unmaintained advisory for the crate.
  • The crate carries a deprecation notice.
  • Every version is yanked.
  • The crate is deleted from crates.io.

A “maintained” statement does not override these signals.

Expected update interval

Each entry gets an expected update interval E, in days.

A library starts from a base chosen by its latest version. The first matching base in the table applies.

Then E is capped at the release count times the days-per-release cap.

Then E doubles when monthly downloads pass their limit. It doubles again when active users pass theirs.

E is never below the dormancy floor.

An app, or a library with no known latest version, uses the dormancy floor.

A step that lacks its signal is left out.

ThresholdValueMeaning
interval.patch_gt3_major_ge1700Base in days: patch above 3 and major at least 1.
interval.patch_gt3450Base in days: patch above 3.
interval.patch_gt0300Base in days: patch above 0.
interval.major_ge1200Base in days: major at least 1.
interval.minor_gt3140Base in days: minor above 3.
interval.other80Base in days: every other version.
interval.days_per_release_cap50Days per release. E is at most the release count times this.
interval.downloads_per_month_double50000Monthly downloads above this double E.
interval.active_users_double10Active users above this double E.
dormancy.min_days365The dormancy floor: smallest E in days, and E for every app.

Dormancy

An entry is dormant when the days since its latest release or latest human commit reach E.

Bot commits do not count.

With neither date known, dormancy is unknown.

Rot signals

Each check counts six rot signals.

  • R1 An outside issue is unanswered past the issue limit, and no maintainer replied within the reply window.
  • R2 A vulnerability advisory is unpatched past the grace window.
  • R3 A library’s former glory is below the lost-glory limit.
  • R4 The latest release requires a deprecated dependency.
  • R5 The repository no longer exists.
  • R6 A library’s latest release fails cargo check on current stable Rust.

Former glory is active users as a share of their peak.

R3 and R6 apply to libraries only. Apps have no former glory and no crate release to check.

A sandbox build check older than its age limit counts as unknown.

A rot check that lacks a signal counts neither way.

ThresholdValueMeaning
rot.unanswered_days270R1 issue limit: days an outside issue stays unanswered.
rot.maintainer_silence_days365R1 reply window: days over which maintainer replies count.
rot.advisory_grace_days60R2 grace window: days an advisory stays unpatched.
rot.lost_glory_below0.5R3 lost-glory limit: a former glory below this share is rot.
rot.build_check_max_age_days45R6 age limit: days a sandbox build check stays valid.

Dead

A dormant entry is dead on a check when it has enough rot signals and no “maintained” statement.

Enough dead checks in a row archive the entry.

Unknown dormancy is not dead.

ThresholdValueMeaning
dormancy.dead_rot_signals2Fewest rot signals that make a dormant entry dead.
dormancy.dead_consecutive_checks2Dead checks in a row that archive an entry.

Finished

A dormant entry with no rot signal that is still adopted is finished.

A “finished” maintainer statement with no rot signal also makes an entry finished.

No rot signal means every rot check is known and none fires.

A library stays adopted on new adopters or on former glory.

An app stays adopted on binary downloads per release.

A finished entry carries a stable label. It counts as active for Featured.

ThresholdValueMeaning
finished.min_former_glory0.8Lowest former glory of a finished library.
finished.min_new_adopters1Fewest new adopters of a finished library.
finished.min_binary_downloads_per_release200Fewest binary downloads per release of a finished app.

New

An entry is New when any one of these holds.

  • Its first release is younger than the age limit.
  • Every version is a prerelease or 0.0.x.
  • A library has fewer active users than the user floor.
ThresholdValueMeaning
new.max_age_days180Age limit: a first release fewer days ago than this is New.
new.min_active_users2User floor: a library with fewer active users than this is New.

Featured library

A library is Featured when it is active and passes every gate.

Active means not dormant, or finished.

  • Active users or new adopters reach their limit.
  • No vulnerability advisory is unpatched past the grace window.
  • The repository link is verified against the crate’s .cargo_vcs_info.json.
  • Former glory reaches its floor.
  • Docs are present.

A gate that lacks its signal does not pass.

ThresholdValueMeaning
library_featured.min_active_users11Fewest active users. This gate or the new-adopter gate passes.
library_featured.min_new_adopters9Fewest new adopters over 12 months. This gate or the active-user gate passes.
library_featured.min_former_glory0.5Lowest former glory, a share from 0 to 1.

Featured app

An app is Featured when it is active and enough of these use signals pass.

  • Binary downloads over the last three releases.
  • Homebrew installs on request over 365 days.
  • Repology repository families that package the app.
  • Docker pull growth over 90 days.

Apps have no dependents signal. ecosyste.ms lists no dependents for a repository that publishes no package.

ThresholdValueMeaning
app_featured.min_signals2How many of the four use signals must pass.
app_featured.binary_downloads884Fewest binary downloads over the last three releases.
app_featured.homebrew_on_request_365d500Fewest Homebrew installs on request over 365 days.
app_featured.repology_families2Fewest Repology repository families that package the app.
app_featured.docker_pull_growth_90d10000Smallest Docker pull growth over 90 days.

Outside approval

An org-affiliated entry that passes Featured needs a featured-approval judgment.

A maintainer outside the ml-rust organization approves it. Without it, the entry is Listed.

Listed

An entry that no rule above places is Listed.

Demotion guard

A Featured entry keeps Featured until a demotion judgment approves the drop.

An instant archive skips this guard.
